# Frontend Block 01

This block turns the existing repo into a runnable Next.js prototype.

## What it adds
- Next.js + TypeScript application scaffold
- Public editorial dashboard
- Imports from `data/seed/*.json`
- Planning score logic
- Priority fixture card
- Priority territory ranking
- Responsive styling
- No external API required for V1

## Upload
Copy these files into the repository root, preserving paths.

## Commit title
`Build first public Fan Opportunity Lab prototype`

## After upload
Run locally:

```bash
npm install
npm run dev
```

Then deploy to Vercel by importing the GitHub repository.
