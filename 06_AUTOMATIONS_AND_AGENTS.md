# Automations and Agents

## Existing monitoring concept

A recurring Fan Opportunity Watch should monitor:
- London City attendance
- competitor attendance
- next-match weather
- fixture / TV schedule changes
- local events
- public holidays
- high-attention sport/TV
- Bromley consumer/business changes

## Recommended automated workflow

### Daily
- check next LCL home fixture
- check weather if within 7 days
- check schedule changes
- check competitor home/away changes
- check high-impact event conflicts

### After every match
- ingest attendance
- ingest scans if internal data available
- record ticket-product mix
- record acquisition channel
- calculate repeat cohorts later

### Weekly
- refresh Matchday Decision Card
- produce one public insight and one internal insight

### Monthly
- attendance trend benchmark
- competitor trend benchmark
- territory conversion review
- local-market / business signal review

## Human approval gates

No agent should automatically:
- spend ad budget
- email fans
- contact sponsors
- change prices
- publish claims externally

Agents should research, score and draft recommendations.
